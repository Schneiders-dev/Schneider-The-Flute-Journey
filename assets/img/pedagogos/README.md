# Retratos dos pedagogos

Coloque aqui os retratos históricos usados nas "paradas" da jornada.

- Nome do arquivo = slug do pedagogo: `quantz`, `boehm`, `altes`, `taffanel`, `gaubert`,
  `andersen`, `kohler`, `fleury`, `moyse`, `rampal`, `galway`, `debost`, `wye`.
- Formatos aceitos: `.webp`, `.jpg`, `.jpeg`, `.png` (proporção ideal 4:5, ~600×750 px).
- Depois de adicionar, rode `npm run build`: o retrato substitui o monograma automaticamente.

## Direitos de uso

Use apenas imagens que possam ser utilizadas legalmente: domínio público
(ex.: muitos retratos do século XIX em Wikimedia Commons, Library of Congress / Dayton C. Miller
Collection) ou imagens licenciadas / autorizadas. Fotografias do século XX (Moyse, Rampal,
Galway, Debost, Wye) geralmente **não** estão em domínio público — obtenha autorização.

## Créditos

Registre a origem e a licença em `credits.json` (o texto aparece como legenda no retrato):

```json
{
  "boehm": "Theobald Boehm — domínio público. Fonte: …",
  "taffanel": "Paul Taffanel — domínio público. Fonte: …"
}
```
